# Example of ENA mapping to MARS ISA-JSON

*This table shows where each piece of information required for an ENA submission must be placed in the MARS ISA-JSON.*

For technology-specific repositories, the unit of submission is the assay, not the study. 

* One ENA STUDY is created per MARS ISA-JSON assay, so the receipt anchors accessions at `studies[title] > assays[@id]`, and anything that must differ per target repository has to live at assay level or below.
* ENA depends on BioSamples having run first. `SAMPLE_DESCRIPTOR/@accession` comes from an accession characteristic on the study sample, which MARS-CLI writes back after the BioSamples step.


| MARS ISA-JSON path                                                            | Repository Obligation | Repository Required value(s)                                                                                                                                                                                                                                                              | Occurrences | What it becomes in ENA                             |
|-------------------------------------------------------------------------------|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------|----------------------------------------------------|
| studies                                                                       | Mandatory             |                                                                                                                                                                                                                                                                                           | 1-n         | iterated                                           |
| studies/title                                                                 | Mandatory             |                                                                                                                                                                                                                                                                                           |           1 | STUDY/DESCRIPTOR/STUDY_TITLE                       |
| studies/description                                                           | Optional              |                                                                                                                                                                                                                                                                                           | 0-1         | STUDY/DESCRIPTOR/STUDY_DESCRIPTION                 |
| studies/comments/name + /value                                                | Optional              |                                                                                                                                                                                                                                                                                           | 0-n         | STUDY/STUDY_ATTRIBUTES/STUDY_ATTRIBUTE (TAG/VALUE) |
| studies/assays                                                                | Mandatory             |                                                                                                                                                                                                                                                                                           | 1-n         | one ENA STUDY per assay                            |
| studies/assays/@id                                                            | Mandatory             |                                                                                                                                                                                                                                                                                           |           1 | STUDY alias (+ EXPERIMENT STUDY_REF)               |
| studies/assays/comments[name=target_repository]/value                         | Mandatory             | ena                                                                                                                                                                                                                                                                                       |           1 | routing only (not emitted)                         |
| studies/assays/comments[name=STUDY_TYPE]/value                                | Mandatory             | Whole Genome Sequencing; Metagenomics; Transcriptome Analysis; Resequencing; Epigenetics; Synthetic Genomics; Forensic or Paleo-genomics; Gene Regulation Study; Cancer Genomics; Population Genomics; RNASeq; Exome Sequencing; Pooled Clone Sequencing; Transcriptome Sequencing; Other |           1 | STUDY_TYPE/@existing_study_type                    |
| studies/assays/comments[name=new_study_type]/value                            | Optional              |                                                                                                                                                                                                                                                                                           | 0-1         | STUDY_TYPE/@new_study_type                         |

| studies/assays/comments/name + /value (any other)                             | Optional              |                                                                                                                                                                                                                                                                                           | 0-n         | STUDY/STUDY_ATTRIBUTES/STUDY_ATTRIBUTE (TAG/VALUE) |
| studies/assays/materials/otherMaterials                                       | Mandatory             |                                                                                                                                                                                                                                                                                           | 1-n         | one ENA EXPERIMENT per library                     |

| studies/assays/materials/otherMaterials/name                                  | Optional              |                                                                                                                                                                                                                                                                                           | 0-1         | fallback EXPERIMENT/TITLE and LIBRARY_NAME         |

| studies/assays/materials/otherMaterials/characteristics/category/@id          | Optional              |                                                                                                                                                                                                                                                                                           | 0-1         | resolves metadata name                             |
| studies/assays/materials/otherMaterials/characteristics/value/annotationValue | Optional              |                                                                                                                                                                                                                                                                                           | 0-1         | ENA experiment field VALUE                         |
| studies/assays/characteristicCategories/@id                                   | Optional              |                                                                                                                                                                                                                                                                                           | 0-n         | lookup key                                         |
| studies/assays/characteristicCategories/characteristicType/annotationValue    | Optional              |                                                                                                                                                                                                                                                                                           | 0-1         | ENA experiment field NAME                          |
| studies/protocols/@id                                                         | Mandatory             |                                                                                                                                                                                                                                                                                           |           1 | lookup key                                         |
| studies/protocols/parameters/@id                                              | Mandatory             |                                                                                                                                                                                                                                                                                           |           1 | lookup key                                         |
| studies/protocols/parameters/parameterName/annotationValue                    | Mandatory             | DESIGN_DESCRIPTION; LIBRARY_STRATEGY; LIBRARY_SOURCE; LIBRARY_SELECTION; LIBRARY_LAYOUT; PLATFORM; INSTRUMENT_MODEL                                                                                                                                                                       | 1-n         | ENA experiment field NAME                          |
| studies/assays/processSequence                                                | Mandatory             |                                                                                                                                                                                                                                                                                           | 1-n         | EXPERIMENT + RUN structure                         |
| studies/assays/processSequence/@id                                            | Mandatory             |                                                                                                                                                                                                                                                                                           |           1 | RUN alias                                          |

| studies/assays/processSequence/inputs/@id                                     | Mandatory             |                                                                                                                                                                                                                                                                                           | 1-n         | identifies the library                             |
| studies/assays/processSequence/outputs/@id                                    | Mandatory             |                                                                                                                                                                                                                                                                                           | 1-n         | links process to data files                        |

| studies/assays/dataFiles/@id                                                  | Mandatory             |                                                                                                                                                                                                                                                                                           |           1 | links to processSequence/outputs                   |

| studies/assays/dataFiles/comments[name=checksum]/value                        | Mandatory             |                                                                                                                                                                                                                                                                                           |           1 | FILE/@checksum                                     |

| studies/materials/samples/@id                                                 | Mandatory             |                                                                                                                                                                                                                                                                                           |           1 | target of the library lineage                      |
| studies/materials/samples/characteristics/category/@id                        | Mandatory             |                                                                                                                                                                                                                                                                                           |           1 | resolves the accession name                        |
| studies/characteristicCategories/characteristicType/annotationValue           | Mandatory             | accession                                                                                                                                                                                                                                                                                 |           1 | resolves SAMPLE_DESCRIPTOR                         |
| studies/materials/samples/characteristics/value/annotationValue               | Mandatory             |                                                                                                                                                                                                                                                                                           |           1 | EXPERIMENT/DESIGN/SAMPLE_DESCRIPTOR/@accession     |
