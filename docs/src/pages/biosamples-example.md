# Example of BioSamples mapping to MARS ISA-JSON

This table shows where each piece of information required for a BioSamples submission must be placed in the MARS ISA-JSON.

| MARS ISA-JSON path                                                                    | Repository Obligation | Repository Required value(s)                                                | Occurrences | What it becomes in BioSamples            |
|---------------------------------------------------------------------------------------|-----------------------|-----------------------------------------------------------------------------|-------------|------------------------------------------|
| studies                                                                               | Mandatory             |                                                                             | 1-n         | iterated                                 |
| studies/title                                                                         | Mandatory             |                                                                             |           1 | receipt path anchor                      |
| studies/characteristicCategories                                                      | Mandatory             |                                                                             | 1-n         | attribute-name lookup table              |
| studies/characteristicCategories/@id                                                  | Mandatory             |                                                                             |           1 | lookup key                               |
| studies/characteristicCategories/characteristicType/annotationValue                   | Mandatory             | organism; tax_id; collection date; geographic location (country and/or sea) |           1 | BioSamples attribute NAME                |
| studies/materials/sources                                                             | Mandatory             |                                                                             | 1-n         | one BioSample record per source          |
| studies/materials/sources/@id                                                         | Mandatory             |                                                                             |           1 | lineage key                              |
| studies/materials/sources/name                                                        | Mandatory             |                                                                             |           1 | BioSample 'name' + receipt path selector |
| studies/materials/sources/characteristics                                             | Mandatory             |                                                                             | 1-n         | BioSample attributes                     |
| studies/materials/sources/characteristics/category/@id                                | Mandatory             |                                                                             |           1 | resolves attribute name                  |
| studies/materials/sources/characteristics/category/characteristicType/annotationValue | Optional              |                                                                             | 0-1         | fallback attribute name                  |
| studies/materials/sources/characteristics/value/annotationValue                       | Mandatory             |                                                                             |           1 | BioSamples attribute VALUE               |
| studies/materials/samples                                                             | Mandatory             |                                                                             | 1-n         | one BioSample record per sample          |
| studies/materials/samples/@id                                                         | Mandatory             |                                                                             |           1 | identity + process lookup                |
| studies/materials/samples/name                                                        | Mandatory             |                                                                             |           1 | BioSample 'name' + receipt path selector |
| studies/materials/samples/derivesFrom/@id                                             | Mandatory             |                                                                             | 1-n         | source lineage                           |
| studies/materials/samples/characteristics                                             | Mandatory             |                                                                             | 1-n         | BioSample attributes                     |
| studies/materials/samples/characteristics/category/@id                                | Mandatory             |                                                                             |           1 | resolves attribute name                  |
| studies/materials/samples/characteristics/category/characteristicType/annotationValue | Optional              |                                                                             | 0-1         | fallback attribute name                  |
| studies/materials/samples/characteristics/value/annotationValue                       | Mandatory             |                                                                             |           1 | BioSamples attribute VALUE               |
| studies/processSequence                                                               | Optional              |                                                                             | 0-n         | sample collection process                |
| studies/processSequence/outputs/@id                                                   | Optional              |                                                                             | 1-n         | locates the collection process           |
| studies/processSequence/inputs/@id                                                    | Optional              |                                                                             | 1-n         | source lineage (fallback)                |
| studies/processSequence/executesProtocol/@id                                          | Optional              |                                                                             |           1 | resolves parameter names                 |
| studies/processSequence/parameterValues/category/@id                                  | Optional              |                                                                             |           1 | resolves attribute name                  |
| studies/processSequence/parameterValues/value/annotationValue                         | Optional              |                                                                             |           1 | BioSamples attribute VALUE               |
| studies/protocols                                                                     | Optional              |                                                                             | 0-n         | parameter-name lookup table              |
| studies/protocols/@id                                                                 | Mandatory             |                                                                             |           1 | lookup key                               |
| studies/protocols/parameters/@id                                                      | Mandatory             |                                                                             |           1 | lookup key                               |
| studies/protocols/parameters/parameterName/annotationValue                            | Mandatory             |                                                                             |           1 | BioSamples attribute NAME                |
